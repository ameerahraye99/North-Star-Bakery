# North Star Bakery

A 4-page static website (Home, Products, About, Contact) built with semantic HTML5.

## Pages
- `index.html` – Home
- `products.html` – Products
- `about.html` – About
- `contact.html` – Contact (includes a pre-order/inquiry form)

## Media
Place your images, audio, and video files in the `media/` folder using these filenames
(referenced by the HTML):
- `bakery-logo.png`
- `bakery-feature-large.jpg`, `bakery-feature-small.jpg`
- `bakery-bread.jpg`, `bakery-signature-loaf.jpg`
- `bakery-storefront.jpg`
- `bakery-welcome.mp3`
- `bakery-behind-scenes.mp4`
